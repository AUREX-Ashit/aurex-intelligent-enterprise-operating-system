Exactly four files changed: `models/c021_offering_definition.py` (+1 shared constant), `services/offering_definition_service.py` (import source only, no behavior change), `repositories/c021_offering_definition_repository.py` (the corrected query), `tests/test_offering_definition.py` (+2 regression tests guarding recurrence).
