# features/

Reserved for future Business Activity feature modules — one subdirectory
per capability (e.g. `features/person/`), each with its own `api/`,
`components/`, and, where genuinely needed, `state/` subfolders.

Intentionally empty. This foundation implements no Business Activity;
placeholder routes for Person Management, Organization, Workspace, and
Settings currently render `components/layout/PlaceholderPage.tsx` directly
from `src/app/`, with nothing here yet to route to.
